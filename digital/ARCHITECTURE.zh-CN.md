# GameTrix 数字版架构

数字版是一个本机运行的单人矩阵练习游戏。它不连接服务器，也不需要账号。窗口固定为 1680 × 1050，卡牌尺寸已加大。每局有八个回合；练习时可以直接结束回合，即使没有出牌。开局及后续每回合最多抽取三张红牌；加法和乘法是内置操作，各自每回合最多使用两次，不再作为实体操作牌发放。有效提交会产生一张新蓝牌。

## 三层结构

```text
run_auto.py / run_student.py ── 选择模式
             │
             ▼
digital/app.py ── 界面与输入
   ├─ digital/table.py ── 手牌、桌面位置、A／操作／B 槽
   └─ digital/card_faces.py ── 印刷卡面与凸起阴影
             │ 调用 Game
             ▼
digital/game.py ── 规则、计分、校验与存档
             │ 调用矩阵函数
             ▼
matrix.py ── 精确矩阵运算与目标条件判断
```

`app.py` 使用 Arcade 展示界面并响应拖放、点击和按键。`table.py` 管理卡牌位于混合手牌、自由摆放的桌面区域，还是 A／操作／B 计算槽；桌面摆放本身不算出牌。计算出的结果固定显示在 Result 槽中作为预览，只有把结果拖到手牌、桌面或 A／B 槽，或按 **Take result** 才会提交并消耗红牌及实体操作牌。学生可直接在结果卡格中填写答案，用 **Check** 或 Enter 校验；错误答案仍留在预览，不消耗卡牌。手牌支持滚轮／触控板连续滚动、拖动滚动条，以及拖牌到窗口边缘时自动滚动。矩阵槽会高亮相关行、列或单元格；单元素和向量操作可点击 A（适用时也可点击 B）中的单元格来指定条目或向量。`card_faces.py` 负责印刷风格的卡面、图像缓存和阴影。`game.py` 不依赖图形界面，管理规则、牌堆、回合、历史与分数。`matrix.py` 是纯计算模块：矩阵运算返回新值，目标判断也由它完成，不读写游戏状态或文件。计算统一使用 `Fraction` 有理数，因此像 `1/3` 这样的结果保持精确，不会因浮点四舍五入而误判。

发到手上的实体操作牌、蓝牌、红牌及已提交的新结果都在同一手牌中。桌面可自由摆牌；手牌连续滚动并可拖动排序。双击或右键卡牌，也可选中后按 `I` 打开完整内容查看器。存档中的 `ui_state` 保存手牌顺序、桌面坐标、计算槽、内置操作选择、滚动位置和未提交的答案草稿，并与游戏状态通过同一次临时文件替换原子写入。没有 `ui_state` 的旧存档仍可读取：所有尚可使用的卡牌会回到混合手牌。

结果槽左侧的 **Remove card** 槽可暂存一张任意类型的牌，最新放入的牌仍可拖回手牌、桌面或计算槽。用另一张牌替换时，`app.py` 先调用 `Game.remove_card` 将旧牌永久移出可用牌，再把新牌放入该槽；同一张牌放回原槽不会移除。移出的操作牌与矩阵分别记录在 `_removed_operations` 和 `_removed_matrices`，不进入循环抽取的弃牌堆。移除蓝牌保留已有积分、去重集合和计算历史；保存校验同时检查可用与已移除的矩阵，因此也能移除起始蓝牌和历史结果。暂存牌及已移除记录均随存档恢复，跨回合保留。**Clear slots** 仅清空三个计算槽。将有效结果预览拖入移除槽，会先正常提交计算，再替换旧牌；答错时两者都不发生。

## 两种启动方式

运行 `run_auto.py` 或 `run_student.py` 都进入同一套界面和规则，区别只是默认模式。自动模式将计算结果留在 Result 槽预览；学生模式也在结果卡格中填写整数或分数，并可校验。两种模式都先由 `calculate` 计算预览，不改变局面；只有将预览拖到有效位置或点击 **Take result** 才尝试提交。`perform` 会重新计算，学生答案正确后才一次性更新手牌、结果蓝牌、分数和历史。答案错误或取消时，预览和答案草稿保留，牌和分数不变。菜单中的随机目标由种子确定；左右箭头改为手动选择目标。

## 牌、计分与保存

蓝牌代表已收集的矩阵，作为输入后仍保留；红牌作为材料，用过就弃掉。每个成功结果都会加入一张新的蓝牌。计分按矩阵的精确数值去重：同一个合格矩阵只得一次分，即使之后再次算出也不会重复得分。游戏状态保存牌的身份、颜色、牌堆与弃牌堆、历史、目标、回合、随机数状态等信息，以便继续原局，而不只是保存画面。

`builtin_remaining` 按本回合已提交历史分别计算加法和乘法的剩余次数。只有取走有效结果才扣除一次；预览、校验、答错、取消及失败操作均不扣次数。按钮和操作槽卡面显示 `2/2`、`1/2` 或 `0/2`，用尽时按钮禁用；模型的 `calculate` 和 `perform` 也会拒绝超额操作。新回合各恢复两次，读档或切换操作不会恢复次数，未用次数不累计。

数字版操作牌共 **90 张**。`BOOSTED_OPERATION_COUNTS` 为低频操作增加独立副本：LU、逆矩阵各 5 张；取负、倍增、向量替换、整体加一和整体减一各 4 张。其余为减法 5、向量加法 5、追加向量 4、转置 3、交换 3、单元素加一与减一各 12、单元素归零 8、向量组合 8。新增 20 张采用 `O40x2` 等独立 ID，沿用原运算规则和卡面。印刷牌组与命令行试玩仍使用其原有分布。

界面在提交出牌、结束回合及返回菜单时自动保存；布局和答案草稿也会保存。新存档为版本 4，包含永久移除牌的记录；版本 1–3 以空移除记录和空暂存槽加载。版本 1 先移除已退役的实体加法／乘法牌；版本 1 和 2 随后把新增的 20 张操作牌确定性地插入待抽牌堆，保留旧待抽牌的相对顺序、当前手牌、弃牌、历史、矩阵卡及结果、分数和随机数状态，不重新发手牌。旧回合已进行的加法／乘法也计入本回合限额；即使旧规则下已用超过两次，已有结果仍保留，只需等下一回合才能再次使用该操作。旧界面布局和草稿在适用时继续保留。自动模式和学生模式分别使用 `digital/saves/auto.json` 与 `digital/saves/student.json`；可通过 `GAMETRIX_SAVE_DIR` 更改保存目录。存档以临时文件写完后再替换旧文件，避免留下半份存档。

## 从哪里修改

| 想修改的内容 | 主要位置 |
| --- | --- |
| 界面布局、交互、答案输入或自动保存触发点 | `digital/app.py` |
| 手牌、桌面位置及 A／操作／B 槽位 | `digital/table.py` |
| 卡牌外观、卡面渲染和阴影 | `digital/card_faces.py` |
| 出牌、抽牌、弃牌、回合、分数或存档规则 | `digital/game.py` |
| 矩阵运算或目标的数学条件 | `matrix.py` |
| 自动／学生模式的启动默认值 | `run_auto.py`、`run_student.py` |

举例：若要改变“合格矩阵何时得分”，查看 `game.py` 的提交逻辑及 `matrix.py` 的 `check`；若要增加一种矩阵运算，还要在游戏操作分派和界面参数设置处接入它。`tests/` 中的矩阵与游戏模型测试可独立于 Arcade 界面检查计算和规则。根目录的命令行版 `gametrix.py` 是较早的独立版本，不是数字版的计算引擎。
