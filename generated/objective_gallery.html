Two blue cards, two red cards, or one of each may be used together. Diagram colors distinguish mathematical roles, not card types. Each matrix has 2–4 rows and 2–4 columns; use exact arithmetic. Print at 100% on A4 with background graphics enabled.

OBJECTIVEC01

Mirror Match

Square 2–4
Example

The matrix must be symmetric, invertible, and non-diagonal.

OBJECTIVEC02+

Signed Identity +

Square 2–4
Example

Every diagonal entry is 1. Every other entry is 0.

OBJECTIVEC02-

Signed Identity -

Square 2–4
Example

Every diagonal entry is −1. Every other entry is 0.

OBJECTIVEC03

Diagonal Diversity

Square 3–4
Example

The matrix must be diagonal. Its diagonal entries must be nonzero, with at least three distinct values.

OBJECTIVEC04

Two-way Balance

Square 3–4
Example

Every row and every column sums to 1. Include at least one negative entry.

OBJECTIVEC05

Opposite Reflection

Square 2–4
Example

Opposite entries have opposite signs. The diagonal is zero, and the matrix is not zero.

OBJECTIVEC06

Return to Start

Square 2–4
Example

Squaring gives the identity. The matrix must be non-diagonal.

OBJECTIVEC07

Volume-Preserving Mix

Square 2–4
Example

The determinant must be 1. Every row and column must contain at least two nonzero entries.

OBJECTIVEC08

Projection

Square 3–4
Example

Squaring must leave the matrix unchanged. It must be non-diagonal, with rank exactly 2.

OBJECTIVEC09

Three-step Collapse

Square 3–4
Example

The third power is zero, but the second power is not zero.

OBJECTIVEC10

Three-step Return

Square 2–4
Example

The third power is the identity. Exclude signed permutation matrices: exactly one nonzero entry per row and column, all ±1.

OBJECTIVEC11

Orthogonal Columns

Tall: 3×2, 4×2, or 4×3
Example

The columns must be nonzero and pairwise orthogonal. The matrix must be tall, with no zero rows.

OBJECTIVEC12

Orthogonal Rows

Wide: 2×3, 2×4, or 3×4
Example

The rows must be nonzero and pairwise orthogonal. The matrix must be wide, with no zero columns.

OBJECTIVEC13

Rectangular Balance

Any non-square shape, each dimension 2–4
Example

For a non-square m × n matrix: each row sums to n, each column to m. Include a negative entry.

OBJECTIVEC14

Zero-sum Orthogonal Rows

Wide: 2×3, 2×4, or 3×4
Example

The rows must be nonzero and pairwise orthogonal, each summing to 0. The matrix must be wide, with no zero columns.
