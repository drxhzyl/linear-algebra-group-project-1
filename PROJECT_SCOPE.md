# GameTrix local card lab

This includes a reproducible card generator, a small command-line dealer, an exact matrix calculator, and a local Arcade game for solo practice. The digital game supports automatic calculation and student-answer verification; see DIGITAL_README.md. Agents choose moves for the separate command-line playtests and investigate difficulty. There is no automated player, exhaustive solver, or multiplayer server.

The generated blue cards are provisional candidates, not certified universal solutions. Playtest failures and timeouts must not be reported as mathematical impossibility. Physical card IDs must be consumed accurately and each reported win must have a checked matrix.

Use only the task directory for new files. Do not modify other school projects.
